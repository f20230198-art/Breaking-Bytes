# [Br]eaking [B]ytes — The Underground Hackathon

Hand-drawn (sketchbook/notebook, NOT comic) Breaking-Bad-*parody* website for a 24-hour hackathon. Two views:
- `/` — scroll-driven comic hero/story page (desert RV → prizes → cook schedule → vault CTA)
- `/dashboard` — functional portal (team formation, problem statements, submissions, live countdown)

**Status (2026-10-26):** Everything is built and tested: landing (DB-driven content), dashboard, admin, Supabase backend (RLS, RPCs, 70 pgTAP tests), web basics, easter eggs, security review. **Pre-registration mode** is on (`event_config.portal_open = false`): the lab shows only Crew + Profile; people give LinkedIn/GitHub (≥1) and admins accept/waitlist crews (see `docs/DATABASE.md` → Pre-registration). Only deployment and real content are left: see **`docs/NEXT-STEPS.md`**. Event is 16–17 Nov 2026.

**Run:** `npm run dev`. **Art:** ChatGPT batch -> `python scripts/assets/organize.py` (sort + alignment report) -> `register.py` for any misaligned layer -> `python scripts/assets/build_scenes.py` (keys magenta, builds plates, writes `public/scenes/` + `src/scenes/layers.generated.json`). Next.js is v16: read `node_modules/next/dist/docs/` before using unfamiliar APIs (middleware is now `proxy.ts`).

## Stack (decided)
- Next.js (App Router) + TypeScript, Tailwind CSS, Framer Motion, Lucide icons
- Supabase: Auth, Postgres (RLS on every table), Realtime for team roster
- Hosting: Railway (Next.js standalone build). Supabase hosted separately.

## Rules
- **Style = LINOCUT block print** (black carved lines, cream paper, dusty orange, crystal blue as the only bright accent). See docs/asset-prompts/00-style-bible.md. No comic pop, no realism. Logo is generated by `scripts/logo/build_logo_sketch.py`.
- **Parody, not copy.** No actor likenesses, no official Breaking Bad logo/fonts/screenshots. Original archetype characters only (see docs/ASSETS.md §Legal).
- **Server is the authority** for time, team membership, leader permissions and submission locking. The client countdown is cosmetic. Never trust client checks alone.
- Every Supabase table has RLS enabled. Service-role key never reaches the browser.
- Style tokens live in `tailwind.config` — don't hardcode hex values in components.
- Image placeholders: `<div className="comic-panel-img" data-asset="hero/rv-desert">` with a comment naming the asset ID from docs/ASSETS.md.
- Respect `prefers-reduced-motion` for all scroll/parallax animation.
- Windows dev machine; project lives in OneDrive — keep `node_modules` out of sync if it causes issues.
