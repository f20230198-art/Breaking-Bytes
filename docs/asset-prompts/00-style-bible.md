# Style Bible: LINOCUT PRINT (locked 2026-10-15)

> Chosen from a 4-way style test (flat poster / **linocut** / ink noir / storyboard). Earlier "realistic hand-drawn" tests were rejected as too detailed and too realistic.

Paste at the top of EVERY image prompt:

```
STYLE: Linocut / woodcut block print. Bold black carved lines and gouge
textures, visible carving marks, slightly uneven ink coverage like a real
hand-pulled print, on warm cream paper. Bold simplified shapes, few
details, clear silhouettes, strong graphic composition. NOT realistic,
NOT painterly, NOT cartoon, NOT 3D, NOT photographic.
INKS (only these): black #111111, cream paper #EFE6D2, dusty desert
orange #C8743A, and crystal blue #13C8E8 used ONLY on glowing light,
liquid or crystals. (Scenes may add ONE extra ink if stated, e.g. olive
green #4E6B3A.)
RULES: no text or lettering, no logos, no real actors or celebrity
likenesses; faces hidden, in shadow, or behind gas masks. Leave the empty
areas requested for website text.
```

Layers: "magenta" = a perfectly flat solid #FF00FF. Magenta doesn't appear in the inks, so it is always safe to key out.
