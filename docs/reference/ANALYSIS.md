## Takeaways (the "level of delivery")
1. **Every section is a fully painted illustration**, not UI on a flat background. Text is integrated *into* the art (graffiti, train windows, name tag). That's why it feels premium, so we need about 1 big illustration per section.
2. **One signature interaction**: the cursor portal lens. We get ours with the blacklight lens.
3. **Typography does a lot of work**: chunky display fonts with 3D extruded shadows, brush/graffiti fonts, and halftone buttons.
4. **Consistent hard-shadow comic buttons and tags.**
5. Their weak spots (contact cards, the sponsor grid) are plain. We can beat them there.
